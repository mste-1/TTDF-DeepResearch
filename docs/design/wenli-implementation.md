## 契约和边界

- 一次提交一项研究，一个最终报告；FIFO，2 个全站执行槽，最多 10 项等待，占槽起 60 分钟超时。
- 全站每天最多成功提交 5 项研究，所有账号含管理员共享；按北京时间（UTC+8）自然日统计，00:00 使用新一天额度。新建和重新生成计入，失败/取消/删除不返还，原请求幂等重放不重复计数。
- 每任务独立进程与初始状态；同用户多任务允许并行。终止、故障保留已持久化成果，重新生成创建新任务。
- 网页与用户接口不公开模型输出字段来源，不因字段回退生成提示；资料引用与真实故障仍展示。
- 管理员可读全站研究，但取消/删除限任务所有者。用户首次改密由服务端强制；账号管理通过 CLI。
- 研究引擎只在子进程导入。API 与管理进程不导入模型图，不在 HTTP 请求内运行研究。
- 配置、密钥、账号数据库不进 Git；部署包不内嵌密钥。代码回滚用版本控制，数据恢复使用 SQLite backup API 备份，生产不自动执行破坏性迁移。

## 验证计划

后端用隔离临时数据库测试权限、CSRF、幂等、每日额度、队列容量、原子领取、取消竞态、事件游标及保留期。每日额度覆盖跨用户并发、北京时间跨日、重启持久化和删除后不返还；队列满测试单独构造足够的日额度或跨日积压。进程测试用显式测试 runner 验证容量、单任务终止、退出清理与恢复。适配测试使用现有图/节点与可控模型，验证观测不会改变结果与路由。前端执行类型检查、构建、关键交互测试与桌面/移动浏览器检查。最终将已通过项、失败修复和环境限制记录在此。

## 信任边界与防护检查

公网浏览器 → 同域 Nginx → API（会话/CSRF/所有者检查）→ SQLite；管理进程 → 独立研究进程 → 模型与搜索服务；公开业务事件从原始观测中按字段白名单生成。外部检索和模型输出均视为不可信文本。

| 风险 | 落地措施与验证 |
| --- | --- |
| 冒用账号、跨用户读取或操作 | 密码哈希、随机会话、过期与撤销、所有者/管理员只读矩阵；越权及首次改密测试 |
| 跨站修改、内容篡改 | SameSite/HttpOnly Cookie、CSRF/Origin 校验、参数化 SQL、请求大小与类型限制 |
| 输出泄露或脚本执行 | 公开响应白名单、Markdown 禁原始 HTML/危险 URL、错误脱敏；下载与事件契约测试 |
| 耗尽执行资源 | 全站每日提交额度、全局队列容量、进程上限、超时、登录限速、独立 IPC；额度竞态、多任务与取消测试 |
| 重复执行或成果丢失 | 幂等键、管理单实例锁、执行代次、终态与成果事务、退出后释放槽；竞态与重启测试 |

## 本轮追加：LangSmith 配置修正

用户在真实联调期间指出 LangSmith 无追踪，并要求读取 `.env`，同时明确当前报告继续、不打断。原因是初版 runner 主动禁用了 tracing 且未加载 `.env`，与用户需要的运维观测不符。修正为仅在研究子进程入口加载用户配置，保留进程显式环境的优先级；移除 runner、Dockerfile、Compose 的强制关闭项。浏览器仍不暴露内部模型字段来源或原始消息。

当时已经开始的那一项研究沿用旧进程配置继续运行，自然完成，期间未重启或重试，也不能补录已经执行的 trace。完成并确认队列及执行槽为空后，重新启动管理进程，移除先前显式关闭 tracing 的启动环境变量。健康检查返回 200、数据库正常、5 槽空闲（当时的历史配置，本次部署准备已改为 2 槽）。后续研究按新的加载规则启用用户配置的 LangSmith；未为验证追踪自动生成第二篇报告。

只读配置验证已确认：主工作树 `.env` 经新入口加载后，LangSmith 判断追踪已启用，配置的项目可通过 SDK 读取。未打印密钥、项目名或端点，未额外创建 trace。加载顺序、环境变量优先级、缺失文件和 flush 成功/异常/超时由隔离测试覆盖。研究退出前最多主动等待 5 秒提交尾部 trace；默认使用 SDK daemon 模式，用户显式设置仍优先。

另补充管理进程对结果送达后的 5 秒退出宽限：SDK 的非 daemon 或线程池线程继续阻塞时，清理整个进程树后保留有效结果，避免把追踪发送迟滞算成研究超时；已接受的取消及实际研究超时仍优先。真实 spawn 测试覆盖非 daemon 线程、ThreadPoolExecutor 和取消竞态。最终报告专用下载已通过浏览器再次验证，下载内容与数据库 Markdown 完全一致。

## 本轮追加：研究连线注释遮挡修正

2026-10-10 用户截图指出边注释看似换行且显示不全。用既有真实报告展开历史复现：71 条边中有 11 对标签相交，均为分发/成果返回或发起审阅/质疑返回。根因是互逆边共用上下端口，默认 smoothstep 标签落在同一或接近的位置，后一标签背景遮住前一文本；不是 SVG 文本自动换行。

调整为分发从右侧 30% 端口连接左侧 30%，返回从左侧 70% 连接右侧 70%，同列主干继续使用上下端口；列步长由 270 增至 320，保留完整标签及真实边方向。放大验收另发现默认左下角缩放控件被“跟随进展”浮层遮挡，将控件明确放到右下角。

验证：现有报告全部 71 个标签在展开历史及约 90% 缩放下两两无重叠、没有标签压住节点；缩小按钮中心命中按钮自身。新增真实 smoothstep 路径几何回归，前端 33 项测试及生产构建通过。未修改后端、研究逻辑或数据库，未发起新研究。修复前后截图保存在忽略目录 `.runtime/wenli-edge-labels-before.jpg` 和 `.runtime/wenli-edge-labels-fixed.jpg`。
