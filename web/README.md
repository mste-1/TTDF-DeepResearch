# 问砺网页

React + TypeScript + Vite。默认访问同域 `/api/v1`，不会把模型密钥放入浏览器，也没有模拟研究数据或演示账户。

开发环境要求 Node.js 22.12+（22 系列）或 24+；依赖版本已精确锁定。

```bash
cd web
npm ci
npm run dev
```

开发页面默认 `http://127.0.0.1:5173`，`/api` 转发至 `http://127.0.0.1:8000`。先启动仓库内的 FastAPI 服务和 Worker 管理进程，再进行真实研究；后台账户通过服务器命令创建。

```bash
npm run typecheck
npm test
npm run build
```

生产构建在 `web/dist/`，由反向代理提供静态文件，未匹配路径回退 `index.html`；`/api/v1` 交给后台服务。不能将仅提供静态文件的 `vite preview` 当作完整后端服务。没有境外字体、CDN 或第三方分析请求。

## 交互边界

- 浏览欢迎页无需登录；提问临时保存在当前标签页会话，登录和首次改密后仍需手动提交。
- 一个提问创建一个任务。请求结果未知时保留幂等键，防止重试生成重复任务。
- 研究页以持久化快照为准。SSE 自动携带重连游标；事件触发节流刷新，连接异常时每五秒只读轮询。刷新、离开页面不会取消研究。
- 桌面显示协作图与节点详情，手机显示阶段列表并提供图入口。当前轮次以外的历史可展开。
- Markdown 禁止原始 HTML、危险 URL 与远程图片自动加载；保留表格、代码、引用和外部资料链接。
- 管理员可切换全部研究。终止与删除只显示在自己的任务上；重新生成始终创建自己所属的新任务。
- 所有页面展示结果与真实研究警告，不展示模型输出字段的内部来源信息。

## 验证

Vitest 覆盖：登录前后的输入保留与不自动提交、网络失败重试幂等、中文输入换行、危险 Markdown、章节目录，以及 SSE 游标去重、终态关闭、断线轮询、切换任务隔离。后端权限和调度不依赖前端控制。
